# 🌱 Modern Home Gardening System

An Arduino-based smart gardening system that automatically waters plants based on soil moisture and provides artificial lighting when ambient light intensity is low.

## Features

- Automatic irrigation
- Soil moisture monitoring
- Automatic lighting
- Energy efficient
- Arduino Uno based
- Simple and low-cost design

## Hardware Components

- Arduino Uno
- Soil Moisture Sensor
- LDR Sensor
- Servo Motor
- RGB LED
- Water Tank
- Water Valve
- Resistors
- Breadboard
- Jumper Wires

## Software

- Arduino IDE
- C/C++

## System Overview

The system continuously monitors the soil moisture and ambient light.

- If soil moisture is below the threshold, the servo opens the valve to water the plant.
- When sufficient moisture is reached, the valve closes.
- If ambient light is low, the LED turns on automatically.
